Piano Digital

Sobre o Projeto
Este é um piano digital interativo, uma aplicação desktop desenvolvida com Python e uma interface gráfica (GUI) construída com Qt Designer. O projeto foi criado como uma atividade prática para solidificar o aprendizado na criação de aplicações de desktop, combinando uma interface visual amigável com a lógica de programação.

Funcionalidades
Notas Musicais: Reproduz o som das notas musicais correspondentes ao serem "tocadas" na interface.

Interface Gráfica (GUI): Exibe as teclas do piano de forma visual e intuitiva.

Interação com o Usuário: As notas são emitidas e exibidas na tela conforme o usuário clica nas teclas virtuais.

Tecnologias Utilizadas
Python: A linguagem principal de programação, responsável pela lógica do piano.

PyQt5: Biblioteca para conectar a lógica do Python com a interface gráfica criada no Qt Designer.

Qt Designer: Ferramenta visual para o desenvolvimento da interface do usuário (.ui).

Sons de Notas: Utiliza uma biblioteca de áudio para reproduzir os sons das notas.
